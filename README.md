# junk-drawer

A collection of personal [Claude Code](https://claude.com/claude-code) skills.

## Skills

- **[bilingual-subtitles](skills/bilingual-subtitles/SKILL.md)** — Extracts English and
  Chinese subtitles from video files (mkv/mp4/etc, via ffprobe/ffmpeg), then merges them
  into a single bilingual `.ass` file with styled colors.

## Usage

Symlink or copy a skill's directory into `~/.claude/skills/` to make it available in
Claude Code.
